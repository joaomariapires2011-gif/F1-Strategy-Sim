# Contributing to F1 Strategy Sim

Thank you for your interest in improving **F1 Strategy Sim**! 🏎️

## How to Contribute

1. **Fork the Repository:** Create your own branch (`git checkout -b feature/new-compound-model`).
2. **Implement Logic:** Ensure mathematical models for tire degradation reflect realistic telemetry data.
3. **Run Unit Tests:** Execute `python -m unittest test_strategy.py` before submitting code.
4. **Submit a PR:** Provide a brief summary of the strategy or bug fix introduced.

## Code Style
Follow standard **PEP 8** style guidelines for all Python code.
